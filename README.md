# Exhibition Place Wayfinding Map — Interactive Prototype

An interactive digital wayfinding case study designed for **Exhibition Place** in Toronto by **Michelle Miyata** (BDES4701).

## 🌟 Overview
This project presents an inclusive wayfinding system designed to empower visitors with mobility, sensory, and accessibility needs across Exhibition Place grounds, BMO Field, Enercare Centre, and Coca-Cola Coliseum.

### Key Features
- **3D Isometric Venue Map**: Interactive grounds map highlighting accessible entrances, direct elevators, all-gender/universal washrooms, and sensory quiet zones.
- **"Get There Your Way" Route Customizer**: Dynamic filtering for step-free routes, low-sensory paths, rest areas, and simplified directions.
- **3-Screen Mobile App Flow**:
  1. Search & Category Selection
  2. Route Preview & Waypoint Verification
  3. Live Simulated AR Guidance with Spoken Audio Cues
- **5W1H Framework**: Persona simulator (Mobility, Low Sensory, Families), Event scenario manager (CNE, TFC games, Concerts), and design methodology.
- **Accessibility**: High-contrast WCAG AAA theme switcher & Web Speech API narration.
